• Host: localhost menunjukkan bahwa MySQL berjalan pada komputer lokal. 
• Username: root merupakan nama pengguna MySQL yang digunakan pada lingkungan pengembangan 
lokal. 
• Password: "" menunjukkan bahwa kata sandi dikosongkan sesuai konfigurasi MySQL lokal yang 
digunakan. 
• Database: db_pwd_nim merupakan nama basis data yang digunakan. Ganti nim dengan NIM masing
masing mahasiswa.
